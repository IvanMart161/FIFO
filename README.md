# Разработка синхронного модуля FIFO

Учебно-исследовательский проект (НИР), выполненный в рамках образовательной программы НИУ МЭИ совместно с НИЦ «Курчатовский институт»-НИИСИ.

## Описание проекта
Данный репозиторий содержит RTL-код параметризованного синхронного буфера FIFO на языке **Verilog**, тестовое окружение для его функциональной верификации, а также средства автоматизации статического анализа на **Python**. 

Проект демонстрирует профессиональный подход к проектированию цифровой аппаратуры: от написания синтезируемого кода до тестирования граничных состояний (механизм Backpressure) и автоматизации работы инженера (EDA Flow).

## Структура репозитория
* `FIFO.v` — синтезируемое RTL-описание аппаратного модуля FIFO.
* `FIFO_tb.v` — интеллектуальное тестовое окружение (testbench) с имитацией параллельного доступа к памяти.
* `static_analyzer.py` — Python-скрипт для статического анализа Verilog-кода (автоматический поиск параметров и зависящих от них шин).
* `ReportFIFO.pdf` — подробная техническая документация и отчет с анализом временных диаграмм.

## Инструкция по запуску

### 1. Верификация модуля
Для симуляции и просмотра временных диаграмм потребуется Icarus Verilog и GTKWave.
```bash
# Компиляция
iverilog -o fifo_sim.out FIFO.v FIFO_tb.v

# Запуск симуляции
vvp fifo_sim.out

# Просмотр графиков
gtkwave fifo_test.vcd
```
